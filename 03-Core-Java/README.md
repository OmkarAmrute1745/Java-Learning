# Core Java

This section builds strong Java language and runtime fundamentals before Exceptions, Collections, Generics, Java 8+, Multithreading, I/O, DSA and Spring Boot.

## Our learning format

Each example follows: **Concept → Why it is needed → Java example → Run → Modify → Practice**.

- String immutability and String Pool
- == vs equals()
- equals() and hashCode()
- Stack vs Heap
- Java is always pass-by-value
- static and final
- Wrapper classes and caching
- BigDecimal for precise decimal calculations
- java.time API
- Interfaces and default methods
