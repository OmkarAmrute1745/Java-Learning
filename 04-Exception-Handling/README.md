# Exception Handling

This section teaches how Java represents, throws, propagates and handles exceptions.

## Learning order

1. Exception Basics
2. try-catch
3. finally
4. throw and throws
5. Custom Exceptions
6. Exception Propagation
7. Exception Handling Patterns
8. Try-With-Resources
9. Exception Practice

## Learning format

**Concept → Why it is needed → Java example → Run → Modify → Practice**

## Important interview topics

- Exception vs Error
- Checked vs unchecked exceptions
- Exception hierarchy
- try-catch-finally
- throw vs throws
- Exception propagation
- Custom checked and unchecked exceptions
- Exception chaining and wrapping
- Try-with-resources and AutoCloseable
- Exception handling in service/business logic
