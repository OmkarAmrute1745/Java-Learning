## How to use this section

1. Read the header comment before the code.
2. Run each Java example and predict its output first.
3. Explain the concept in your own words.
4. State time/space complexity for coding questions.
5. For backend scenarios, cover correctness, failure handling, tests, observability, and trade-offs.

Java examples target Java 21+. Markdown notes cover SQL and framework/system-design topics where runnable Java code is not the best format.
