# 09 - Java I/O

Complete Java I/O learning section using the same pattern as OOP, Java 8+, and Multithreading.

## Structure
- 01-IO-Basics
- 02-Byte-Streams
- 03-Character-Streams
- 04-Data-And-Serialization
- 05-Console-And-Print
- 06-File-And-NIO
- 07-NIO-Advanced
- 08-Buffered-And-Performance
- 09-IO-Practice

## Topics covered
File handling, byte streams, character streams, buffering, Data streams, object streams, serialization, Scanner, BufferedReader, PrintWriter, PrintStream, copy/move/delete, Path, Files, Files.lines, DirectoryStream, ByteArray streams, transferTo, performance, and interview practice.

## Interview focus
InputStream vs OutputStream, Reader vs Writer, File vs Path, Scanner vs BufferedReader, buffering, serialization, NIO Files API, and I/O performance.

## Backend connection
Java I/O is used for uploads, downloads, reports, logs, exports, configuration, file processing, and stream-based data processing.

## Practice
Run every class, change inputs, observe output, and explain each concept with a practical backend example.

Do not commit generated .class files or generated demo files.
