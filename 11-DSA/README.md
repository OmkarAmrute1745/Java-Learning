# 11 - DSA

Data Structures and Algorithms learning section for Java interview preparation.

## Structure

- 01-DSA-Basics
- 02-Searching
- 03-Sorting
- 04-Linked-List
- 05-Stack-Queue
- 06-Hashing
- 07-Trees
- 08-DSA-Practice

## Topics

- Big-O time and space complexity
- Arrays and strings
- Recursion
- Linear and binary search
- Two pointers and sliding window
- Bubble, selection, insertion, and merge sort
- Singly and doubly linked lists
- Linked-list reversal and cycle detection
- Stack, queue, deque, and parentheses validation
- HashMap/HashSet patterns
- Two Sum and frequency counting
- Binary trees and BST
- DFS and BFS
- Maximum subarray and merge problems
- Interview-style problem solving

## Learning approach

For every problem:
1. Understand the problem.
2. Identify the suitable data structure or pattern.
3. Write the simple solution first.
4. Analyze time and space complexity.
5. Improve the solution when constraints require it.
6. Explain the solution clearly as if answering an interview.

All examples are standalone Java programs and target Java 21+.
